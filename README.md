# BCA Study Portal — V2

Navigation-focused skeleton for the BCA 1st Year C Programming syllabus.

## Included
- 5 modules
- Syllabus-aligned topic names and sequence
- Left-side collapsible module menu
- Topic selection
- Active topic highlighting
- Previous / Next navigation
- Placeholder note pages
- Static HTML/CSS/JavaScript
- GitHub Pages ready

## Main files
- `index.html` — structure
- `css/style.css` — styling
- `js/syllabus.js` — master syllabus
- `js/notes.js` — notes placeholders
- `js/app.js` — navigation

Actual notes will be added later, topic by topic.
